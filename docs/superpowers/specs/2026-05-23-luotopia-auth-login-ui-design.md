# Luotopia 账户登录页 UI 设计

## 目标

客户端只保留一个 Luotopia 账户入口页。用户输入手机号或邮箱后，可使用验证码或密码登录；如果凭证对应的新账户需要注册，由服务端在登录流程中自动完成。

## 页面结构

- 页面标题为“Luotopia 账户”。
- 第一栏为“手机号 / 邮箱”。
- 第二栏由当前登录方式决定：
  - 验证码登录：显示“验证码”输入框和“发送验证码”按钮。
  - 账号密码登录：显示“密码”输入框，并保留显示/隐藏密码按钮。
- 主按钮只显示“登录”。
- 主按钮下方显示小字“新账户将自动注册”。
- 再下方显示登录方式切换：
  - 当前为验证码登录时，显示“账号密码登录”。
  - 当前为账号密码登录时，显示“验证码登录”。
  - 显示“微信登录”和“QQ 登录”入口。

## 交互规则

- 客户端使用严格正则判断第一栏内容。
- 内容符合手机号时，验证码接口使用 `targetType: phone`。
- 内容符合邮箱时，验证码接口使用 `targetType: email`。
- 内容既不符合手机号也不符合邮箱时，直接提示用户修改，不进入服务端流程。
- 密码登录仍使用现有 `identifier` 字段传递手机号或邮箱。
- 微信和 QQ 登录当前只作为入口展示；在没有实际接口前，点击后提示暂未开放。

## 路由与文件

- 删除独立注册页文件。
- 删除注册页路由常量、路由声明和导出。
- 移除登录页里跳转注册页的入口，避免后续维护两套账户入口。
