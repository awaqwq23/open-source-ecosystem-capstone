#### 3 主页topbar文字逻辑：

当这周属于学期内的话，直接显示：第X周，例：第3周
当这周不属于某个学期，但是这周七天全部属于某个单独的月时，显示：X月第X周，例：四月第3周
当这周既不属于某个学期，也不全部属于某个单独的月时，显示：XXXX年第X周，例：2026年第18周。

特别地，如果这周是本周，那么下面的日期（eg.5/4~5/10）不显示，转而显示周数（也就是上面大字标题本应显示的内容，按上文的规则），而上面大字标题显示“本周”两个字。

这个改的问题在于：本周时，本周文字和周数文字的位置不符合预期，应该交换一下。
还有就是：在点击周数时，应该是直接跳出时间选择弹窗，而非现在的两步式。
