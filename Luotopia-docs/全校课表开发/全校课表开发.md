# 全校课表开发

## 功能定位

全校课表提供武汉大学全校课程数据的查询与同步能力。管理员每学期上传一次数据集包，系统处理后下发给客户端。

此功能是客户端"全校课表"、"蹭课"、"选课推荐"的依赖。

## 数据流

```text
管理员上传 SQLite gzip 包
       │
       ▼
服务端 ParsePackage → BuildRecords → previewImport → ApplyImport
       │
       ├── 写入 GORM (PostgreSQL): entity 表 + change 表
       ├── 发布 SQLite 数据集包到对象存储
       └── 通过 Pull API 返回增量/全量给客户端
              │
              ▼
客户端 PullService → 下载 bundle 或应用 change 列表
       │
       ▼
客户端 Drift SQLite 数据库（与服务端 bundle 同构）
       │
       ▼
AllSchoolTimetableRepository 提供查询接口
```

## 服务端实现

### 数据集上传格式

服务端接受 **SQLite gzip 压缩包**（非 CSV、非 HTML 爬取）。包内 SQLite 数据库的表结构与发布时的 bundle 同构：

- `school_timetable_term_rows` — 学期元信息
- `school_timetable_courses` — 课程目录（跨学期共享）
- `school_timetable_course_terms` — 学期课程（学期 + 课程维度）
- `school_timetable_instructors` — 教师课程（跨学期共享）
- `school_timetable_offerings` — 教学班（最细粒度的排课单元）
- `school_timetable_audiences` — 面向对象切片（年级、专业、学院等）
- `school_timetable_source_rows` — 原始 HTML 行归档
- `school_timetable_meeting_rules` — 排课规则（星期、节次、地点）
- `school_timetable_meeting_weeks` — 周次展开

### 实体模型（Entity Model）

数据被归一化为 7 种实体类型：

| 实体类型 | 跨学期共享 | 说明 |
|----------|-----------|------|
| `course` | 是 | 课程目录（课程号+名称+学分决定 ID） |
| `instructor_course` | 是 | 教师-课程关联（教师名+课程目录决定 ID） |
| `term` | 否 | 学期元信息 |
| `term_course` | 否 | 某学期下的课程聚合 |
| `offering` | 否 | 具体教学班 |
| `audience` | 否 | 教学班面向对象切片 |
| `meeting_rule` | 否 | 排课规则（含展开的周次） |
| `meeting_week` | 否 | 排课周次展开（meeting_rule 的子表） |
| `source_row` | 否 | 原始行归档 |

### 版本化存储

每次导入产生一个新版本号（递增）。每条实体的变更记录在 `school_timetable_changes` 表中。跨学期共享的实体（course、instructor_course）不会被删除。

### 数据集包发布

导入完成后，服务端自动将所有实体写入一个临时的 SQLite 数据库，gzip 压缩后上传到对象存储。bundle 的 URL 和 checksum 记录在数据集状态中。

### Pull API 集成

Pull API 根据客户端提供的 `school_timetable_version` 决定返回策略：

- **增量模式**（默认）：变更数 ≤ 10000 时，返回 `SchoolTimetableChange[]`
- **全量模式**（降级）：变更数 > 10000 时，返回 `bundle` 下载地址，客户端下载完整替换

## 客户端实现

### 本地数据库

客户端使用 Drift（SQLite）维护一套与服务端 bundle 同构的表结构。支持两种同步方式：

1. **增量应用**：`applyChanges()` — 逐条 upsert/delete 实体
2. **全量替换**：`replaceFromBundle()` — ATTACH DATABASE + INSERT SELECT 整表替换

### 查询能力

- **全文搜索**：使用 FTS5 虚拟表 `school_timetable_search_fts` 支持中文关键词搜索
- **条件筛选**：支持开课学院、年级、专业、星期、教学楼等筛选
- **教学班匹配**：`matchPersonalCourse()` 根据用户课表定位到具体教学班

### UI 交互

全校课表客户端采用三级页面结构：

1. **搜索页**：按课程号聚合展示，支持轻量/专业两种查询模式
2. **教学班列表页**：同一课程号下的不同教学班概览
3. **教学班详情页**：单个教学班的完整信息

两种查询模式：

- **轻量查询**：默认模式，提供学期、年级、时间、地点、学院快捷筛选
- **专业查询**：全屏筛选页，支持多维度精确筛选

详见 `全校课表UIUX交互设计.md`。
