服务端模块结构（当前实际）
==========================

internal/
├── backend/
│   └── admin/           ← 后台管理（access + 管理编排）
├── modules/
│   ├── account/         ← 账号体系
│   │   ├── auth/        ← 认证（注册登录、凭证、会话）
│   │   └── profile/     ← 用户公开资料
│   ├── agenda-sync/     ← 事项跨设备同步
│   ├── forum/           ← 珞珈防空洞论坛
│   ├── whusb/           ← 课程评价社区
│   ├── push-and-pull/   ← 信息推送
│   │   ├── weather/     ← 天气
│   │   ├── hot_update/  ← 热更新脚本
│   │   ├── notification/ ← 推送通知（预留）
│   │   └── user-stats/  ← 用户统计（预留）
│   └── sub_apps/        ← 客户端校园子应用
│       ├── scores/          ← 课程给分
│       ├── study-materials/ ← 学习资料
│       └── timetable/       ← 全校课表
├── platform/            ← 基础设施
├── database/            ← 数据库迁移
└── ...
