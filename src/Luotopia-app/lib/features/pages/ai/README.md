## ai 模块说明

对应需求中的 AI 页，以 session 为原子单元存储和展示聊天记录。

### 负责范围

- AI session 查询、切换与展示。
- 顶栏左侧显示页面用途标题，右侧提供会话列表入口与新建对话按钮。
- 当前主页面只展示当前 session。
- 将自然语言解析为事项创建请求。
- 依据事项数据回答用户问题。
- 对接用户自定义 AI API 地址。
- 页头、操作按钮、输入框与会话列表二级页直接使用 `shadcn_flutter` 组件。

### 目录分工

- `data/`：AI 接口调用、聊天记录存储、请求响应 DTO。
- `domain/`：提问类型判定、事项创建意图、聊天范围规则。
- `presentation/`：AI 页面、聊天列表、输入区、`ViewModel`。

### 依赖提醒

该模块会读取事项数据，但聊天上下文按需求不做长上下文传递。
