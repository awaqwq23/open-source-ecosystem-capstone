## core 目录说明

这里放全项目共用的底层基础设施，要求可被所有功能模块安全依赖。

### 适合放入 core 的内容

- 常量、错误定义、扩展方法、工具函数。
- 网络、存储、通知、平台适配、依赖注入。
- 全局主题、国际化底层支持、组件库接入配置。

### 不应放入 core 的内容

- 与“事项”“日程”“任务”“备忘”强相关的业务规则。
- 某个具体页面专属的 UI 组件。

### 与 shared 的区别

- `core/` 偏技术基础设施。
- `shared/` 偏跨页面共享的业务概念。

### 当前约束

- 页面框架层统一依赖 `shadcn_flutter`，`core/` 不再新增私有 Scaffold、AppBar、Sheet 之类的替代实现。
- 全局可复用图标语义统一收口到 `core/theme/app_icons.dart`；页面层新增稳定图标时优先复用 `AppIcons`，不要直接散写 `Icons.*`。
- 只有一次性、局部且尚未沉淀为通用语义的图标，才允许在页面内直接使用 `Icons.*`。
