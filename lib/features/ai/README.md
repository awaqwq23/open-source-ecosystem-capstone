## ai 模块说明

对应需求中的 AI 页，按日存储聊天记录，并按日/周/月范围展示。

### 负责范围

- AI 聊天记录查询与展示。
- 顶栏左侧显示页面用途标题，右侧提供日历按钮切换日/周/月范围。
- 时间范围切换与按范围聚合展示。
- 将自然语言解析为事项创建请求。
- 依据事项数据回答用户问题。
- 对接用户自定义 AI API 地址。

### 目录分工

- `data/`：AI 接口调用、聊天记录存储、请求响应 DTO。
- `domain/`：提问类型判定、事项创建意图、聊天范围规则。
- `presentation/`：AI 页面、聊天列表、输入区、`ViewModel`。

### 依赖提醒

该模块会读取事项数据，但聊天上下文按需求不做长上下文传递。
