## time_picker 模块说明

这是跨页面复用的时间选择功能模块，对应需求中的日 / 周 / 月选择组件。

### 负责范围

- 顶部年月跳转与确认操作。
- 月表格展示、日期格点击、周格点击、月格点击。
- 根据调用目标返回日、周、月三种结果。
- 左右滑动切换月份。

### 设计原因

虽然它常以组件形式出现，但业务规则复杂，且会被主页和 AI 页复用，因此单独成模块。

### UI 约束

- 选择器页面本身使用 `shadcn_flutter` 页面骨架实现。
- 未来如果恢复为弹出式选择器，也应优先使用组件库原生 overlay / dialog / sheet 能力。

### 目录分工

- `data/`：如有需要，可放节假日、本地化日历数据源。
- `domain/`：日期选择规则、返回值规则、周月映射逻辑。
- `presentation/`：选择器页面、弹层、网格组件、`ViewModel`。
