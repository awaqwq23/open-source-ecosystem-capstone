## item_editor 模块说明

对应事项添加页与事项编辑页，统一承载“日程 / 任务 / 备忘”的编辑流程。

### 负责范围

- 事项类型切换。
- 名称、详情、地点、颜色、日期、时间、提醒、重复等表单项。
- 根据入口场景自动预填默认值。
- 编辑已有事项时的数据回填。

### 目录分工

- `data/`：表单保存、本地草稿、DTO 与仓储实现。
- `domain/`：事项表单规则、字段校验、默认值生成。
- `presentation/`：添加页、编辑页、表单组件、`ViewModel`。

### 备注

后续如果新增“快速添加”“批量编辑”，优先继续放在本模块内部。
