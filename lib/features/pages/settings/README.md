## settings 模块说明

对应设置主页及各二级设置页。

### 负责范围

- 设置首页列表。
- 设置页统一使用左标题 top bar，设置主页右侧提供快捷定位入口。
- 通用设置、主页设置、列表页设置、关于等二级页。
- 全局时间块配置、语言、主题、同步、通知、桌面小组件配置入口。
- 设置页页头与快捷入口弹层直接使用 `shadcn_flutter` 组件。

### 目录分工

- `data/`：设置持久化、本地缓存、平台配置读写。
- `domain/`：设置项模型、默认值、配置合法性校验。
- `presentation/`：设置首页、设置详情页、设置组件、`ViewModel`。
