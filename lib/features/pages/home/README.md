## home 模块说明

对应需求中的主页表格页，是应用默认首页。

### 负责范围

- 周视图与月视图的表格化时间展示。
- 顶栏时间段切换、左右滑动切换时间段。
- 时间块网格、事项跨格覆盖展示、重叠透明度计算。
- 长按空白格进入新增事项，点击或长按事项进入详情/编辑。

### 目录分工

- `data/`：主页所需的数据聚合、表格渲染用 DTO、同步后的展示数据整理。
- `domain/`：表格时间轴、事项布局、重叠判定等业务规则。
- `presentation/`：主页页面、`ViewModel`、表格组件、事项块组件。

### 依赖提醒

主页会强依赖 `time_picker` 与共享事项模型，但不直接依赖其他页面实现。

主页使用 `shadcn_flutter.AppBar` 作为顶部栏基座，并保留需求中的居中标题视觉与左右切换交互。
