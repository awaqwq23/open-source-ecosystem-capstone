## shared 目录说明

这里放跨多个功能模块共享的业务对象与业务型复用 UI，但不承载应用框架层。

### 适合放入 shared 的内容

- 三类事项的公共枚举、公共模型、值对象。
- 颜色、提醒、重复规则、时间段描述等共享业务概念。
- 多个页面都会使用的业务型组件。

### 目录意图

- `enums/`：事项类型、排序类型、时间范围类型等枚举。
- `models/`：跨模块共享的数据模型或领域模型外壳。
- `value_objects/`：时间段、提醒策略、重复规则等不可变值对象。
- `mappers/`：共享模型之间的转换。
- `services/`：跨模块的轻业务服务。
- `widgets/`：跨 feature 复用的业务组件，而不是页面骨架、顶部栏、弹层脚手架这类框架组件。

### 约束

- `shared/` 不承载应用启动逻辑。
- `shared/` 不再提供私有页面框架组件，页面布局优先直接使用 `shadcn_flutter`。
- 若某能力只服务单一 feature，应回到对应 feature 内部。
