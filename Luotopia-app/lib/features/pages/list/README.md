## list 模块说明

对应需求中的列表页，交互参考 Microsoft To Do。

### 负责范围

- 标签页列表切换，如“我的一天”“全部事项”“任务列表”等。
- 顶栏左侧显示当前标签名，右侧提供标签切换与列表设置入口。
- 列表排序、手动重排、主题切换入口。
- 完成状态切换、重要标记、左右滑动编辑/删除。
- 右下角浮动新增按钮的上下文预填。
- 页面顶部栏与底部弹层直接使用 `shadcn_flutter` 组件实现。

### 目录分工

- `data/`：标签页数据源、列表过滤结果、排序配置持久化。
- `domain/`：列表过滤、排序、分组、完成态业务规则。
- `presentation/`：列表页、标签切换组件、列表项组件、`ViewModel`。
